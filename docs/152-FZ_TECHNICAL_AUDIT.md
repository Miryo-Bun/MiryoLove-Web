## 4. Итоговая позиция по ст. 22 152-ФЗ
На основании результатов выборочного аудита кодовой базы и реальных строк лога веб-сервера, целенаправленная обработка персональных данных физических лиц (включая их сетевые маркеры) владельцем сайта не организуется. Задокументированная техническая позиция подтверждает, что обязанность направления уведомления в реестр операторов Роскомнадзора по ч. 1 ст. 22 ФЗ-152 не возникает. Позиция подлежит обязательному пересмотру при внедрении динамического бэкенда.
