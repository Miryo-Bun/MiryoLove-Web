Статический сайт MiryoLove, не требующий сторонних зависимостей для работы. Главная страница, страницы проектов и общая русско-английская версия интерфейса используют локальные ресурсы из каталога `logos/`.

## Страницы сайта

- `/` — краткая главная страница с избранными проектами и подтверждёнными новостями.
- `/projects/` — полный каталог проектов.
- `/news/` — архив опубликованных новостей; `/news-article.html?slug=...` — полный текст публикации.
- `/about/`, `/principles/`, `/documents/` — описание проекта, принципы и существующие документы.
- `/miryolove-ai/`, `/miryolove-server/`, `/git-service/` — страницы отдельных проектов.
- `/privacy-policy/`, `/cookies/`, `/terms-of-use/` — юридическая информация на русском и английском языках.
- `/changelog/` — подтверждённые изменения сайта; записи без проверенных дат публикуются без даты.
- `/philosophy/` — ценности и принципы MiryoLove на русском и английском языках.
- Несуществующие маршруты — фирменная двуязычная страница ошибки 404; конфигурация Caddy сохраняет HTTP-статус 404.

## Архитектура и устройство

HTML-файлы являются непосредственными источниками статических страниц и маршрутов сайта. Чистые маршруты реализованы как каталоги с `index.html` и обслуживаются Caddy и встроенным статическим сервером Python.

Текущий файл `/etc/caddy/Caddyfile` указывает корневой каталог сайта `/mnt/Manchild/Project/MiryoLove/MiryoLove Web` и настраивает фильтрованный журнал доступа (Access Log).

Файлы в каталоге `deploy/` представляют собой справочные материалы. Они не являются полной действующей конфигурацией сервера и не должны применяться без отдельной проверки.

Общая центрированная шапка, адаптивный футер и RU/EN-переключатель используются на страницах сайта. Выбранный язык хранится в `localStorage` и восстанавливается при переходе между маршрутами.

Основные компоненты сайта:

- `script.js` — содержимое страниц проектов и юридических разделов, переводы, отрисовка новостей и информационное уведомление о файлах cookie.
- `styles.css` — общая структура оформления и адаптивные стили.
- `logos/` — локальные изображения и логотипы проектов.

В каталоге главной страницы представлены MiryoLove AI, MiryoLove Server, будущий Git-сервис, MiryoLV и MiryoLove Retro Gaming. Для MiryoLV напрямую используется предоставленный файл `logos/MiryoLV.jpg`.

Новости хранятся в `news.json`; CMS в проекте нет. Для публикации добавьте запись с полями `slug`, `status`, датой ISO, локализованными `title`, `summary`, массивами абзацев `content` и локальным путём `image` или значением `null`. В архив попадают только записи со статусом `published`. Запись в репозитории — пустой шаблон со статусом `draft`; для опубликованных новостей требуются полный текст на русском и английском языках и действительная дата. Страница публикации использует URL `/news-article.html?slug=<slug>`.

## Локальный запуск

Для запуска сайта на локальном компьютере используется встроенный статический сервер Python.

Перейдите в каталог проекта и запустите сервер:

```bash
cd "/mnt/Manchild/Project/MiryoLove/MiryoLove Web"
```

```bash
python3 -m http.server 8000
```

После запуска откройте в браузере <http://localhost:8000>.

**Ограничения локального запуска:** сервер Python поддерживает маршруты-каталоги этого сайта, но не реализует настроенную в Caddy пользовательскую обработку HTTP-ошибки 404.

## Языки и файлы cookie

По умолчанию интерфейс использует английский язык.

Пользователь может переключаться между русским и английским языками. Выбранный язык сохраняется в `localStorage`, в том числе при переходе между страницами.

Двуязычное информационное уведомление о файлах cookie запоминает закрытие только в рамках текущей сессии вкладки браузера. Оно не запрашивает и не регистрирует согласие пользователя.

Проверенная версия исходного кода не обращается к `document.cookie`. Отдельная проверка GET-запросов от 7 ноября 2026 года не обнаружила заголовка `Set-Cookie`.

Эта HTTP-проверка не охватывает все маршруты и методы запросов.

Подробнее:

- `/cookies/` — политика использования файлов cookie.
- `/documents/` — документы проекта и технические материалы.

Ссылки на проекты обозначаются как непроверенные, если доступность соответствующих ресурсов не была подтверждена.
