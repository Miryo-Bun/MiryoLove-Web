Статический сайт MiryoLove, не требующий сторонних зависимостей для работы. Главная страница, страницы проектов и общая русско-английская версия интерфейса используют локальные ресурсы из каталога `logos/`.

## Страницы сайта

- `/` — главная страница MiryoLove и каталог проектов.
- `/miryolove-ai/`, `/miryolove-server/`, `/git-service/` — страницы отдельных проектов.
- `/privacy-policy/`, `/cookies/`, `/terms-of-use/` — юридическая информация на русском и английском языках.
- `/changelog/` — подтверждённые изменения сайта; записи без проверенных дат публикуются без даты.
- `/philosophy/` — ценности и принципы MiryoLove на русском и английском языках.

Для несуществующих маршрутов предусмотрена фирменная двуязычная страница ошибки 404. Конфигурация Caddy сохраняет HTTP-статус 404.

## Архитектура и устройство

HTML-файлы являются непосредственными источниками статических страниц и маршрутов сайта.

Текущий файл `/etc/caddy/Caddyfile` указывает корневой каталог сайта:

`/mnt/Manchild/Project/MiryoLove/MiryoLove Web`

Также в конфигурации настроен фильтрованный журнал доступа (Access Log).

Файлы в каталоге `deploy/` представляют собой справочные материалы. Они не являются полной действующей конфигурацией сервера и не должны применяться без отдельной проверки.

Основные компоненты сайта:

- `script.js` — содержимое страниц проектов и юридических разделов, переводы и информационное уведомление о файлах cookie.
- `styles.css` — общая структура оформления и адаптивные стили.
- `logos/` — локальные изображения и логотипы проектов.

## Локальный запуск

Для запуска сайта на локальном компьютере используется встроенный статический сервер Python.

Перейдите в каталог проекта:

```bash
cd "/mnt/Manchild/Project/MiryoLove/MiryoLove Web"
```

Запустите сервер:

```bash
python3 -m http.server 8000
```

После запуска откройте в браузере:

<http://localhost:8000>

**Ограничения локального запуска:** сервер Python предоставляет исходные HTML-файлы напрямую и не реализует чистые маршруты (clean URLs) или пользовательскую обработку HTTP-ошибки 404, настроенную в Caddy.

## Языки и файлы cookie

По умолчанию интерфейс использует английский язык.

Пользователь может переключаться между русским и английским языками. Выбранный язык сохраняется в `localStorage`, в том числе при переходе между страницами.

Двуязычное информационное уведомление о файлах cookie запоминает закрытие только в рамках текущей сессии вкладки браузера. Оно не запрашивает и не регистрирует согласие пользователя.

Проверенная версия исходного кода не обращается к `document.cookie`. Отдельная проверка GET-запросов от 7 ноября 2026 года не обнаружила заголовка `Set-Cookie`.

Эта HTTP-проверка не охватывает все маршруты и методы запросов.

Подробнее:
- `/cookies/` — политика использования файлов cookie.
- `docs/` — технические аудиты проекта.

Ссылки на проекты обозначаются как непроверенные, если доступность соответствующих ресурсов не была подтверждена.
